### **Phase 2: Reaper.grim Integration** (Week 2)
**Goal:** Reaper can spawn/manage Bolt containers and call MCP tools

#### **2.1 gRPC Client Library for Reaper**
```zig
// Thin Zig wrapper around Bolt's gRPC API
const Bolt = @import("bolt");

const client = try Bolt.Client.connect("localhost:50051");

// Spawn container with MCP enabled
const container = try client.runContainer(.{
    .image = "bolt://dev:latest",
    .mcp_enabled = true,
    .mcp_tools = &.{"filesystem", "shell", "gpu"},
});

// Call MCP tool through gRPC
const result = try client.callMCPTool(.{
    .container_id = container.id,
    .tool_name = "shell:exec",
    .arguments = .{ .command = "cargo build" },
});
```
